# P2-E 內容與分鏡

版本：Showcase 1.0.0

主題：`pump-demo-v1` 循環水泵異常維修

受眾：求職面試官、工程主管、第一次接觸產品的訪客

## 閱讀層級

- 30 秒：知道這是一個讓 AI 安全使用企業工具的治理工作台。
- 3 分鐘：走完水泵查詢、提案、核準、冪等寫入與 Trace。
- 6 分鐘：查看設定版本、migration、備份還原、證據與限制。

## 十章分鏡

| 章節 | 第一次接觸產品的說法 | 視覺 | 互動 | 資料模式 |
|---|---|---|---|---|
| 01 作品總覽 | AI 可以建議，但政策才決定能不能寫入 | 授權電路與水泵狀態牌 | 跳至完整故事 | 合成＋歷史摘要 |
| 02 兩種客戶模式 | 同一台水泵，服務商與資產團隊需要不同流程 | Profile 差異面板 | 切換 Profile | 離線示範 |
| 03 四工具 | 先查狀態、歷史與零件，最後才申請建單 | 四張工具卡與 Schema 表單 | 選工具、送出查詢 | 離線示範 |
| 04 權限與 scope | 看得到哪些設備由後端交集決定 | 角色矩陣與 scope 環 | 切角色、嘗試跨設備 | 離線示範 |
| 05 單／雙人核準 | 寫入不是按下按鈕就成功 | 提案卡與核準軌道 | 核準、自審、重複複核 | 離線示範 |
| 06 冪等與恢復 | 重送不會多一張工單 | 請求合流圖 | 重送、並行、結果不明 | 離線示範 |
| 07 設定版本 | 客製化會改欄位與政策，但不能擴權 | 版本差異板 | 預覽、套用模擬、還原 | 離線示範 |
| 08 Migration 與還原 | 備份資料關係，不帶回執行權 | Ledger、包含／排除、五個零 | 竄改、還原 | 合成＋歷史摘要 |
| 09 Trace 與隔離 | 每一步可追查，五個環境不混用 | Trace 節點與隔離區 | 展開節點、阻擋跨環境 | 離線示範 |
| 10 證據與限制 | 看得到做過什麼，也看得到沒有做什麼 | 證據板與限制清單 | 下載摘要、列印、主動開工作台 | 歷史摘要＋入口 |

## 響應式原型

- 1440：固定左側章節導覽，內容區雙欄，互動控制與結果並列。
- 768：導覽改成頂部橫向捲動，內容依重要性分為主卡與輔助卡。
- 390：所有控制元件單欄，流程水平線改成垂直時間軸，表格改為卡片；不依 hover 顯示資訊。

## 鍵盤路徑

跳到主要內容 → Profile 切換 → 工具選擇 → 查詢 → 角色與 scope → 建立提案 → 核準 → 重送 → Trace → 證據下載。對話框若存在需鎖定焦點並支援 Escape；所有狀態變化使用 `aria-live`。

## 文案規則

- 全站繁體中文；首次出現 MCP、Schema、Trace 時提供白話說明。
- 「離線示範」「歷史實測」「真實工作台入口」固定使用不同標籤。
- 不使用「即時」「正式企業」「生產部署」「AI 自主執行」等未被證據支持的說法。
