## 三種模式

- 離線互動示範：所有按鈕只改 React 與 `sessionStorage` 狀態。
- 歷史實測證據：只使用 `build_showcase_evidence.py` 產生的白名單摘要。
- 真實工作台入口：使用者明確點擊 `8130` 普通連結；網站不探查、不登入、不呼叫 API。
