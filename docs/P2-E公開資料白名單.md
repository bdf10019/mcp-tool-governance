# P2-E 公開資料白名單

## 唯一公開來源

`scripts/build_showcase_evidence.py` 只讀取 P2-B～P2-D-3 的本機驗收 JSON，選出固定欄位後產生網站資料與下載摘要。Showcase 不在瀏覽器中讀取 `reports`。

## 可公開欄位

- 作品名稱、核心版本、Showcase 版本、里程碑與驗收日期。
- 三個唯讀工具、一個核準後寫入工具。
- 單／雙人核準、自審阻擋、管理者繞過阻擋、冪等與結果不明恢復是否通過。
- 最新本機測試分母：後端、前端、E2E、建置與響應式狀態。
- migration schema、套用筆數、pending、drift 與零權威五項計數。
- 合成資料、離線展示、未交付項目與非即時聲明。

## 禁止欄位

- 帳號、密碼、雜湊、Cookie、Session、CSRF、Token 或驗證上下文。
- 完整 SHA、隨機 ID、備份 ID、還原環境 ID、主機名與私人絕對路徑。
- 正式資料庫、備份檔、完整 reports、原始 Trace、工具 payload、提案／工單內文。
- 可復活核準、重新執行工具或推知私人環境的狀態。

## 截圖規則

現有控制台截圖含測試帳號、隨機識別或本機路徑，不直接複製到網站。首版以明示為「離線示範」的 HTML 元件重建操作故事；若未來納入真實截圖，必須在隔離合成環境重新取得並逐張通過白名單檢查。

## 一致性

網站內嵌資料、`public/data/evidence-summary.json`、JSON 下載及 Markdown 下載由同一產生器輸出。測試比較公開欄位與 SHA-256，避免頁面與下載內容分歧。
